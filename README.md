# 风险治理系统桌面端

基于 Electron + Vue 3 构建的风险监控与治理桌面应用。登录后通过通知 WebSocket 接收实时风险告警，并提供风险列表、详情分析、处置操作、系统托盘提醒和桌面端配置能力。

## 功能清单

### 风险监测

- 风险总览卡片：全部、P0、P1、P2、已处理。
- 风险列表：支持分页、优先级、事件类型、处置状态和时间范围筛选。
- 事件类型动态加载，以及表格、看板、时间轴视图入口。
- 支持通用告警、被拦截访问、漏洞情报等事件详情展示。
- 支持处置状态切换，以及处置后的列表和详情同步。

### 风险治理

- 关键漏洞治理和复测。
- 高危端口治理和复测。
- 弱口令治理。
- 访问关系、资产发现、漏洞情报和被拦截访问等事件处理。
- 支持规则下发、访问关系确认和攻击事件处置等服务端操作。

### 实时通知

- 应用级通知 WebSocket，登录后自动连接并断线重连。
- P0：常驻桌面提醒、可配置声音、托盘未读数量和托盘 P0 列表。
- P1：可配置桌面弹窗和自动消失时间。
- P2：按通知提示配置处理，默认不打断用户。
- 支持锁屏状态下的通知策略和勿扰时段。
- `summary` 推送只更新顶部统计数字，不触发列表请求。
- `event` / `event_updated` 只在风险监测页触发列表同步，并采用 2 秒防抖合并请求。
- 详情弹窗打开期间不因实时事件刷新列表，关闭弹窗后自动同步一次。
- 点击 P0 桌面/托盘通知后进入 P0 待处理列表，并跨分页定位目标告警。

### 应用设置

- 风险等级通知配置：P0 声音、P0 勿扰时段、P0 锁屏提醒、P1 弹窗、P1 自动消失时间、P2 提醒等。
- 开机自启和启动后最小化到托盘。
- 应用锁：手动锁定、空闲自动锁定、锁屏期间 P0 通知策略。
- 数据与存储：查看本地目录，清理过期日志、引擎缓存和离线操作队列。
- 登录与账号：配置服务端地址及账号信息。
- 主题切换、窗口控制和本地诊断日志导出。

## 实时通知请求规则

| 场景 | 行为 |
| --- | --- |
| 收到 `summary` | 只更新顶部卡片数字，不调用 `notify/list` |
| 点击顶部卡片 | 按当前筛选获取事件类型和 `notify/list` |
| 收到 `event` 或 `event_updated` | 仅风险监测页进入 2 秒防抖刷新 |
| 详情弹窗打开时收到事件 | 暂存刷新标记，不刷新全量列表 |
| 详情弹窗关闭 | 自动刷新一次列表 |
| 新列表请求产生 | 取消旧请求结果，避免堆积和旧数据覆盖新数据 |

## 技术栈

- 前端：Vue 3、TypeScript、Pinia、Element Plus
- 桌面运行时：Electron
- 构建工具：Vite、Sass、electron-builder
- 网络请求：Axios；Electron 环境通过 IPC 代理 HTTP 请求
- 实时通信：通知 WebSocket、治理/复测相关 WebSocket
- 本地能力：系统托盘、桌面通知、窗口状态记忆、应用锁、日志管理、离线操作队列

## 项目结构

```text
src/
├─api/                  服务端接口封装
├─components/           通用组件和风险治理组件
├─stores/               Pinia 状态管理
├─utils/                请求、WebSocket、日志和本地能力
├─views/riskMonitor/    风险监测页面及详情弹窗
├─views/setting/        设置页面及配置模块
├─views/Login.vue       登录页面
└─router/               路由配置

electron/
├─main.ts               Electron 主进程入口
├─preload.ts            预加载脚本
└─main/                 IPC、托盘、窗口、通知和日志管理
```

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建前端和 Electron 主进程

```bash
npm run build:web
```

### 构建完整应用

```bash
npm run build
```

构建产物默认输出到 `dist/` 和 `dist-electron/`。安装包由 `electron-builder` 配置生成，输出目录为 `release/`。

## 服务端配置

应用默认使用 `/api` 作为接口前缀，也可以在“登录与账号”中配置完整服务端地址，例如：

```text
https://10.10.10.99
```

风险监测相关接口包括：

- `POST /notify/summary`
- `POST /notify/list`
- `POST /notify/event-types`
- `POST /notify/detail`
- `POST /notify/status/update`
- `/api/websocket/notify`

具体接口参数以 `src/api/` 下的类型和封装为准。

## 说明

- 应用需要登录后才能建立实时通知连接。
- 通知连接断开时，顶部会显示重连状态，并支持手动重试。
- 本地日志、缓存和离线队列属于设备本地数据，不等同于服务端风险数据。
- 当前打包配置包含 Windows NSIS 和 macOS DMG 目标；实际发布平台以 `electron-builder.json5` 和构建环境为准。
